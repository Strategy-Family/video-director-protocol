# دستورپخت‌های آماده — شش نوع ویدیوی پرکاربرد

> هر دستورپخت یک زنجیره‌ی آماده است: به کارگردان بگویید «دستورپخت شماره‌ی [x] را برای این بریف اجرا کن» تا همان مسیر را با جزئیات برند شما بچیند. برآورد اعتبارها مال اوایل آبان ۱۴۰۵ است و با احتساب دو سه تلاش برای هر شات؛ قبل از تولید، قیمت روز ابزارتان را چک کنید.

## ۱. ریلز سینمایی (قلاب جذب) — حدود ۷۰۰ تا ۹۰۰ اعتبار
سناریو و شات‌لیست با کارگردان ← لوکیشن‌ها و فریم‌ها با Nano Banana 2.1 ← پیش‌نویس هر شات با Grok Imagine 480p تا حرکت و قاب قفل شود ← شات‌های نهایی با Seedance 2 pro 720p و فقط شات قهرمان با Seedance 2.5 ← نریشن ElevenLabs ← موزیک Suno ← تدوین.
قاعده‌ی طلایی: تا پیش‌نویس ارزان را ندیده‌اید، سراغ مدل گران نروید.

## ۲. تیزر محصول ۱۰ تا ۱۵ ثانیه‌ای — حدود ۳۰۰ اعتبار
عکس واقعی محصول + دو سه فریم با Nano Banana ← دو شات ۵ ثانیه‌ای با Seedance 2 pro (یا ارزان‌تر: Kling 3.0 Turbo) ← متن فارسی در تدوین، نه در مدل.

## ۳. گوینده‌ی هوش مصنوعی با دیالوگ فارسی — سه راه
- ارزان (تست بازار): فریم گوینده + Grok Imagine با دیالوگ فارسی داخل پرامپت — حدود ۲۵۰ اعتبار برای ۴۰ ثانیه.
- متن دقیق کلمه‌به‌کلمه (ویدیوی فروش): ElevenLabs فارسی + Lip Sync V2 Pro — گران‌تر ولی متن مال شماست.
- بهترین کیفیت: Google Omni — حدود ۹۰ اعتبار برای هر کلیپ ۱۰ ثانیه‌ای.

## ۴. ترند حرکتی («کاراکترت را بگذار جای آدم ویدیو») — ارزان‌ترین: حدود ۷۰ اعتبار برای ۱۰ ثانیه
ویدیوی حرکت مرجع + عکس کاراکتر ← Kling Motion 2.6. اگر صدا و حالت چهره‌ی ویدیوی اصلی هم باید بماند ← Genjutsu.
هشدار: برای استفاده از ویدیوی دیگران اجازه لازم است.

## ۵. ریلز ارزان روزانه — زیر ۳۰ اعتبار
یک تصویر ارزان ← Grok Imagine 480p پنج ثانیه ← نریشن Turbo ← تدوین. با یک پلن متوسط، ماهی بیست و چند تای این‌ها درمی‌آید؛ این سبکِ حجم روزانه‌ی پیج است.

## ۶. دوبله‌ی کلیپ خارجی به فارسی
ترجمه با چت ← صدای فارسی ElevenLabs ← برای کلیپ کوتاه: Omni ویدیو‌به‌ویدیو (ارزان‌تر)؛ برای کلیپ بلندتر: Lip Sync V3.

## یادآوری بودجه
یک پلن متوسط (حدود ۸۰۰ اعتبار در ماه) تقریباً این‌قدر جا دارد: یک ریلز سینمایی + یک ریلز گوینده + هشت ریلز ارزان + ده عکس و کاروسل + صدا و موزیک. بیشتر از این یعنی پلن بالاتر.
