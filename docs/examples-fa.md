# نمونه درخواست‌ها

همیشه آدرس ریپو را اول پیام بگذارید و عکس‌ها را همان‌جا ضمیمه کنید.

## اولین ویدیو (حالت پیش‌فرض)
```
[آدرس ریپو]
این عکس کاراکتر برندم و این‌ها عکس محصول‌هام هستن.
ایده: توی یه کوچه‌ی آجری صبح پاییز، کت و کیف رو نشون بده. ویدیو رو توی هوشا با Veo می‌سازم، حدود ۱۵ ثانیه.
```
جواب شامل استوری‌بورد، حرکت امضا، پرامپت هر دو کلیپ و فریم ۱ است. برای فریم بعدی فقط بنویسید:
```
بعدی
```
اگر خود کارگردان گفت فریم با فریم قبل یکی نیست (پس‌زمینه یا دوربین جابه‌جا شده)، بنویسید:
```
اصلاح کن
```

## ویدیوی بلند
```
[آدرس ریپو]
عکس کاراکتر و محصول‌ها ضمیمه است. یه ویدیوی حدود ۴۰ ثانیه‌ای می‌خوام: صبح پاییز توی پیاده‌روی چنار، اول از دور میاد، بعد جزئیات شال و کت، آخرش ست کامل. با Veo توی هوشا می‌سازم.
```

## ایده ندارم
```
[آدرس ریپو]
این عکس کاراکتر و این عکس محصولمه. خودت دو تا ایده بده و با بهترینش برو جلو.
```

## ویدیو با مدل سنگین
```
[آدرس ریپو]
عکس کاراکتر و عکس محصول ضمیمه است. ایده: [یک جمله]. ویدیو رو با Seedance توی هوشا می‌سازم.
```

## ترند
```
[آدرس ریپو]
این ترند رو برای برندم بساز: [توضیح کوتاه ترند یا لینکش]. عکس کاراکتر و محصول ضمیمه است.
```

## خروجی خراب شد
```
شات ۲ رو دو بار گرفتم؛ هر دو بار انگار عکسه که فقط یه کم تکون می‌خوره و صورتش هم کمی عوض شده.
```

## فریم یا ویدیو رو به من نشون بده تا چک کنی
```
این فریم دوم است. طبق چک‌لیست فریم بررسیش کن و اگه چیزی در رفته بگو.
```

## حالت کامل (برای کار مفصل‌تر)
```
[آدرس ریپو]
حالت کامل. بریف برند و بریف ویدیو ضمیمه است.
```

## یک نکته
اگر روی عکس محصولتان برچسب یا لوگوی برند دیگری هست، قبل از عکس گرفتن آن را تا کنید یا بپوشانید. مدل‌های تصویر لوگوها را می‌بینند و گاهی دوباره می‌سازند، و آن وقت پست شما با لوگوی برند دیگری منتشر می‌شود.
