# نمونه درخواست‌ها

یادتان باشد اول آدرس ریپو را در چت بگذارید و بریف برند و بریف ویدیو را ضمیمه کنید.

## شروع یک تولید
```
طبق این پروتکل، تولید این ویدیو را کارگردانی کن.
بریف برند، بریف ویدیو، عکس مرجع کاراکتر و عکس محصول ضمیمه است. در هوشا تولید می‌کنم.
```

## اجرای یک دستورپخت آماده
```
دستورپخت «تیزر محصول» را برای این محصول اجرا کن؛ عکس واقعی‌اش ضمیمه است.
```

## فقط شات‌لیست می‌خواهم
```
طبق پروتکل فقط تا مرحله‌ی شات‌لیست برو؛ سناریو ضمیمه است. ادامه را بعداً می‌گیرم.
```

## ادامه در چت جدید
```
این کارت تولید و خروجی‌های مراحل قبل است: [پیست کارت تولید + شات‌لیست]
از همین‌جا ادامه بده؛ چیزی را از اول نساز.
```

## وقتی مدل‌ها یا قیمت‌ها فرق دارند
```
ابزار من این مدل‌ها را دارد با این قیمت‌ها: [پیست فهرست]
ران‌شیت را با همین‌ها دوباره بچین.
```

## خروجی بد شد (عیب‌یابی)
```
شات ۲ را دو بار گرفتم؛ هر دو بار صورت کاراکتر عوض شد و حرکت دستش هم خراب است.
طبق مرحله‌ی عیب‌یابی بگو مشکل از چیست و ارزان‌ترین راه حلش کدام است.
```

## یک نکته
«کارت تولید» را که آخر هر پیام می‌آید یک جا نگه دارید؛ حافظه‌ی پروژه‌ی شماست. لازم نیست بودجه اعلام کنید: کارگردان همیشه کم‌هزینه‌ترین مسیری را می‌چیند که کیفیت انتشار را حفظ کند — ارزانی مال پیش‌نویس و تست است، نه شات نهایی — و در ران‌شیت، گزینه‌ی ارزان‌تر و سینمایی‌تر را هم کنارش می‌گذارد.
